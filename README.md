## Executive Summary of Findings

### Pool A — Numerical Modality
1. **A1 (Breast Cancer Diagnosis):** Standardized L2-regularized Logistic Regression achieved peak ROC-AUC (0.994) and malignant F1 (0.963). Accuracy is severely misleading in screening contexts where false negatives cost human lives. Threshold shifting from 0.50 to 0.23 elevated malignant recall to 97.6% with negligible precision degradation.
2. **A2 (Concrete Compressive Strength):** Linear regression violates the logarithmic hydration curve of cement curing. Adding non-linear domain features (`water/cement ratio` and `log(age)`) slashed linear error. Random Forest regressor led overall performance with RMSE of 4.79 MPa (R² = 0.916).
3. **A3 (Dry Bean Variety Recognition):** A 2-hidden-layer MLP achieved 93.3% test accuracy and 0.941 Macro-F1 across 7 cultivars. Morphological overlap between Sira and Dermason dominates error cases. Class-weight balancing boosted minority recall (Bombay, Barbunya). PCA dimensionality analysis demonstrated that 8 components preserve 98.6% of peak performance.

### Pool B — Mixed (Numerical + Text) Modality
4. **B1 (Fake Job Postings):** Detecting employment scams in imbalanced data (4.8% fraud). Structured metadata alone yielded PR-AUC of 0.448, and text TF-IDF alone yielded 0.722; combining both modalities surged PR-AUC to 0.812 (+0.364 gain), achieving an F1 score of 0.771 upon validation threshold calibration.
5. **B2 (Wine Critic Scores):** De-duplication was strictly applied prior to train/val/test splitting to prevent benchmark leakage. Sensory tasting notes lifted prediction R² from 0.382 (price/origin metadata) to 0.704 (combined). Score-band analysis confirms pronounced regression to the mean at extreme boundaries (80-84 and 95-100).
6. **B3 (Clothing Review Star Ratings):** The concurrent indicator `Recommended IND` was strictly omitted to prevent leakage. Class-weighted multimodal logistic regression achieved an ordinal MAE of 0.48 stars. Reframing the ordinal 5-class problem into a 3-class commercial sentiment framework (Negative 1-2, Neutral 3, Positive 4-5) yielded 87.4% accuracy and 0.768 Macro-F1.

### Pool C — Sequence-to-Sequence Modality
7. **C1 (English-to-Urdu Machine Translation):** Additive Bahdanau attention successfully bridges SVO-to-SOV grammatical reordering. Beam search (k=4) improved BLEU from 14.82 to 16.21 on 2,000 OPUS test pairs. Pretrained MarianMT scored 21.84 BLEU owing to large-scale multilingual pretraining.
8. **C2 (News Summarisation):** The extractive Lead-1 heuristic fails on BBC XSum (16.3% ROUGE-1) due to high reference abstractiveness (38.4% novel bigrams). Custom BiGRU reached 28.45% ROUGE-1, while fine-tuned T5-small scored 38.62% ROUGE-1 with 90% factual accuracy under tri-gram repetition blocking.
9. **C3 (Image Captioning):** The CNN-LSTM merge architecture with frozen ResNet-50 features achieved 17.1% BLEU-4 with beam search (and 22.1% under spatial attention). While beam search optimized n-gram precision, tracking vocabulary diversity revealed a 23.0% vocabulary contraction, demonstrating the tendency of beam decoding toward repetitive generic templates.
